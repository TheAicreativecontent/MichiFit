Cómo se generan
---------------
Los de ahora son pixel art hecho por código:
    cd pixel && python generar_michis.py

Para sustituirlos por ilustraciones, guarda una HOJA DE PERSONAJE con
todos los michis en UNA sola imagen (así salen consistentes entre sí) y:
    cd pixel && python recortar_hoja.py ../IMG/cuerpos.png

El recortador separa los gatos del texto de las etiquetas, los recorta,
los cuadra y los comprime. Si el orden no cuadra, se ajusta la lista
ORDEN dentro del script.
